# Grok 재작성 프롬프트 — 태국어판 (2026-11-03; 일본어앱 rewrite_grok.md ⑨항 포함, 태국어는 ❓ 규칙 추가)

흐름: 이 세션 초안(JSON) → 이 프롬프트로 Grok 재작성(한 요청 = 편 1개, 모델 「전문가」, 태국어 방 「태국어 회화 검수」) → 받은 대사를 JSON 에 넣고(`tools/apply_rewrite.py`) 검사기 통과용 최소 수정 → 사용자 리뷰. 판정형 검수는 쓰지 않는다(AI 지문이 안 지워짐). 「유지」가 많은 답은 버리고 다시 받는다.

```
[{code}] 아래는 태국어 학습 앱(한국인 학습자용) 회화 1편의 **초안**입니다. 이 초안을 베이스로, 지금 방콕에 사는 실제 태국 사람이 이 장면에서 그대로 말할 법한 대사로 **다시 써 주세요**(판정이 아니라 재작성). AI 가 만든 티(교과서체·번역투·과한 설명·정리된 느낌)가 전혀 안 나야 합니다. 당신이 X·LINE·TikTok·현장에서 본 진짜 말을 쓰세요 — 구어 축약(ม่ะ·อะ·ป่ะ·จ้า·งั้น·ไง), 조사(ครับ/ค่ะ/คะ/นะ/สิ/เนอะ/อะ/เหอะ), 요즘 자주 쓰는 짧은 말(จริงดิ·เอาจริง·อะไรนะ·ชิลๆ·เว่อร์·555·โอเคป่ะ…) 포함.
{roles} 장면: {scene}. 말투: {register}. 지역: 방콕 표준 구어(사투리 없음).
지킬 것: ① 턴 수 {n}·화자 순서 그대로 ② 변수 {{name}}·{{country}}·{{city}} 그대로(학습자 A 의 국적·이름은 정하지 않음) ③ 학습 목표 표현 {targets} 이 자연스럽게 들어갈 것(위치는 바꿔도 됨) ④ 한 턴 1~2문장은 **유지**(초보용이지만 지나치게 깎지 말 것 — 짧게 만드는 것이 목적이 아니라 '진짜 말'로 바꾸는 것이 목적) ⑤ 반전(턴 {twist} 근처)의 **킥(웃음·놀람 포인트)은 코믹하게, 더 세게** — 방콕에서 실제로 일어날 법한 사고로 ⑥ 연애 장면이면 설렘·두근거림·상상을 자극하는 여백(말을 다 하지 않고 멈추기, 침묵 …, 끝의 여운)을 살릴 것 — 성적 묘사는 금지 ⑦ 학습자가 **암기하고 싶어지는, 기억하기 쉬운 한 줄**이 편마다 하나는 있어야 함(짧고 리듬 있는 말) ⑧ 특정 국적·실존 브랜드·연예인 대사 금지 ⑨ 학습자 A 는 남성 기준(ผม/ครับ)으로 써 주세요 — 여성판은 앱이 규칙으로 바꿉니다.
⑩ **모든 줄을 새로 쓴다** — 초안 문장을 그대로 두는 「유지」는 금지(유지가 많은 답은 버립니다). 뜻은 지키되 말은 당신 것으로.
⑪ 태국어가 **확실하지 않은 줄은 줄 끝에 ❓** 를 붙이세요(구어 축약·조사·속어의 최신성이 애매할 때). 그 줄만 사람이 다시 봅니다.
출력 형식(이것만, 다른 설명 없이): 줄마다 `번호 화자: 태국어 / 한국어(태국어 말투에 맞춘 자연스러운 한국어 구어) / 초안과 다르게 쓴 이유 한 줄`. 마지막에 `추천 표현:` 이 장면에서 태국 사람이 진짜 자주 쓰는데 못 넣은 짧은 표현 2개(태국어 / 뜻).

초안:
{lines}
```

채우는 자리: {code} 편id · {roles} 화자 역할(예: A = 학습자(외국인, 남성 기준), B = 편의점 점원(여)) · {scene} 장면 한 줄 · {register} 말투(존댓말/반말/채팅) · {n} 턴 수 · {targets} 목표 표현 · {twist} 반전 턴 · {lines} 초안(번호 화자: 태국어 / 한국어). 생성 `tools/make_rewrite_prompt.py <편.json>` → 전송 `tools/grok_send.py` → 반영 `tools/apply_rewrite.py`.
