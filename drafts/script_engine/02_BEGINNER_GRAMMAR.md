# 초급 스크립트의 문법 기준 — 기초 교재 15종 집계 (2026-09-23)

> 한국어권 태국어 기초 교재(표준교재·첫걸음류·패턴류·회화류 15종)의 단원 구성을 훑어 **어떤 문법·용법 요소를 공통으로 가르치는지** 세었다.

> 초급 스크립트(`scripts_src_beginner.txt`)는 이 표의 **1군을 빠짐없이, 2군을 절반 이상** 쓰는 것을 목표로 쓴다. 포함도는 `python check_beginner.py` 로 센다.

## 초급 문장의 규칙 (빌더·검수 기준)

1. 한 턴은 짧은 문장 1~2개, 태국어 15음절 안팎. 접속사로 길게 잇지 않는다.
2. 공손형 고정: 학습자는 ครับ/ค่ะ 를 거의 매 턴 붙인다. 반말 대명사·속어 없음. 상대가 친구여도 존댓말이 기본(นะ·สิ 정도만).
3. 턴마다 노트에 `문법:` 으로 쓰인 요소를 적는다 — 앱에서 '이 문장의 문법' 카드로 보여 주고, 검사기가 센다.
4. 같은 요소를 스크립트 안에서 최소 두 번 다른 문장으로 보여 준다(질문 → 답에서 재사용).
5. 재미는 초급이라도 뺀 게 아니다 — 속마음(설렘·승부·인정·일탈)은 상황과 마지막 두 턴으로 만든다. 문장 난이도가 아니라 **장면**이 자극적이다.
