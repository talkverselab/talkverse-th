# 루트 단어 — 설계·데이터·규칙 메모 (태국어앱, 2026-11-02 정리)

다른 언어앱(인도네시아어 등)이 같은 기능을 만들 때 보라고 흩어진 설계를 한 곳에 모은 것. 코드 기준: `lib/services/root_service.dart`, `lib/screens/thai_roots_screen.dart`, `lib/widgets/vocab_sheet.dart`, `tools/vocab_pipeline/build_vocab.py`(`build_roots`), 데이터 `assets/data/vocab/th_roots.json`.

## 1. 개념

- **루트 단어** = 여러 단어 안에 공통으로 들어가는 핵심 형태소이면서 그 자체도 단어인 것. 예 น้ำ(물) → น้ำแข็ง(얼음)·น้ำตาล(설탕)·น้ำผลไม้(주스)·แม่น้ำ(강). 중국어앱의 발음부(声旁) 화면에 대응.
- 목적: 단어를 외우는 게 아니라 **조각의 뜻을 알면 새 단어를 풀어 읽게** 하기. 가족 시트 안내문 그대로 — "같은 루트 = 뜻이 이어지는 경향. 앞에 붙으면 루트+수식, 뒤에 붙으면 수식+루트로 읽어 보세요."
- 태국어 181개. 교착·합성이 많은 언어(인도네시아어의 어근 + 접사 me-/ber-/-kan/-an)에도 같은 틀이 맞는다 — 단, 접사 변형(어근 첫 자음 탈락 등)은 "포함 관계"만으로는 못 잡으니 §4 변형 규칙을 언어에 맞게 더해야 한다.

## 2. 데이터 (`th_roots.json`)

```json
{ "meta": {...},
  "roots":  [ {"th":"น้ำ","reading":"남","ko":"물","note":"물·액체·즙 → 얼음(น้ำแข็ง)·설탕(น้ำตาล)·…"} ],
  "pieces": { "ค้า":"장사하다", "ตู้":"장(欌)·함" },
  "reject": [ "ยา|ยาว", "ยา|ยาก" ] }
```
- `roots`: 루트 표제어·독음·뜻·`note`(뜻의 확장 방향 + 대표 파생어 3~4개 — 카드 뒷면/헤더용). **파생어 목록은 데이터에 넣지 않는다** — 앱이 단어장에서 포함 관계로 계산한다(단어장이 바뀌어도 자동 갱신).
- `pieces`: 루트가 아닌데 분해 공식에 자주 나오는 조각의 뜻(검토본). 단어장에도 루트에도 없을 때만 참조.
- `reject`: `루트|단어` — 철자만 우연히 포함(ยา 약 ∉ ยาว 길다). 가족에서 뺀다.
- 원본은 `tools/vocab_pipeline/roots_curated.json`(사람 검토본, 같은 형식)·`root_pieces.json`. `build_vocab.py` 가 합쳐 에셋으로 쓴다.

## 3. 루트 뽑기 (`build_vocab.py build_roots`)

1. 후보 = 단어장 표제어 + 빈도 상위 단어 중 **길이 2~7자, 띄어쓰기 없음, 그 언어 문자만, STOP_ROOTS(문법어·대명사 등) 제외**.
2. 후보가 **다른 단어 3개 이상에 부분 문자열로 들어가면** 후보 채택 → `root_candidates.json`(포함 수 내림차순, 검토용).
3. 사람이 검토해 `roots_curated.json` 에 남긴다(뜻이 실제로 이어지는 것만; 우연 일치는 `reject` 로). 검토본이 있으면 후보 상위 80개 자동 선정은 쓰지 않는다.

## 4. 파생 판정 (앱, `RootService.containsAtBoundary`)

문자열 포함 + **음절 경계** 검사:
- 루트 바로 **뒤**가 결합 모음·성조 부호(ั ิ ี ึ ื ุ ู ็ ่ ้ ๊ ๋ ์ ฺ …)나 뒤따르는 모음(ะ า ำ)이면 ✕ — 루트가 끝나지 않은 것.
- 루트 바로 **앞**이 앞모음(เ แ โ ใ ไ)이면 ✕ — 그 모음은 루트 첫 자음과 한 음절.
- 앞이 자음이면 허용(모음 없는 음절일 수 있음).
- `reject` 목록에 있으면 ✕.
- 가족은 `strong`(위 규칙 통과) / `weak`(후보) 로 나뉘고, 화면은 strong 을 **앞에 붙음 / 뒤에 붙음 / 가운데** 세 섹션으로 나눈다(단어가 루트로 시작/끝/그 밖).
- 인도네시아어 대응: 경계 규칙 대신 접사 표(me-, mem-, men-, meng-, meny-, ber-, ter-, di-, pe-, -kan, -i, -an, -nya)와 첫 자음 변형(p→m, t→n, k→ng, s→ny)을 두고, "어근 + 접사 조합이 그 단어와 같은가"로 판정하는 편이 맞다.

## 5. 단계(어느 단어 풀에서 찾나, `RootStage`)

all(단어장 전체, 단어 행 링크용 기본) · 빈도 1~250 · ~500 · ~750 · ~1000 · 표준(빈도 1000 + 교육부 기초 단어). 루트 화면 위 버튼으로 바꾸면 가족 수가 달라진다. 루트 정렬 = 가족 수 내림차순.

## 6. 화면

- **루트 화면**(`thai_roots_screen.dart`): 루트 카드 그리드(루트·독음·뜻·가족 수) → 탭하면 **가족 시트**: 루트 헤더(note) + 앞/뒤/가운데 섹션 타일. 타일 = 파생어(루트 글자 강조 밑줄)·독음·뜻·스피커, 탭하면 단어 상세.
- **분해 공식**(`RootService.formula`): `방 + 물 ⇒ 화장실` 처럼 조각 뜻을 이어 보여 준다. 조각 뜻은 단어장 → 루트 → pieces 순으로 찾고, 조각 안에 다른 루트가 있으면 재분해. 자음 하나·부호로 시작·괄호 같은 파편은 우연 일치로 본다.
- **단어 상세 시트**(`vocab_sheet.dart`): 단어 안의 루트를 칩으로 보여 주고 탭하면 그 루트 가족으로 이동(`focusRoot`·`fromWord` 로 해당 단어 하이라이트).
- 홈 메뉴 타일 「루트 단어」(부제 `น้ำ → น้ำแข็ง`).

## 7. 주의

- 루트 뜻·note 는 자체 작성(출처·교재명 없음). 공개 저장소 규칙 그대로.
- 루트 뽑기는 단어장 크기에 민감하다 — 태국어는 2026-11-02 저작권 정리로 단어장이 577개로 줄어 가족 수가 줄었다(루트 181개는 유지). 단어장이 늘면 `build_vocab.py` 를 다시 돌려 후보를 재검토.
- 테스트 `test/data_assets_test.dart` 「루트 단어 에셋 + 경계 규칙」 — 경계 규칙의 예시 케이스가 들어 있으니 언어별 규칙을 바꾸면 테스트도 같이.
