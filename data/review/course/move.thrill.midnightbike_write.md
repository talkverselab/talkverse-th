1 B: ขึ้นมาสิ ไปเที่ยวกลางคืนกัน อย่าถามว่าไปไหน / 타. 밤 드라이브 가자. 어디 가는지 묻지 마. / 「ขึ้นมา = 타다」「กลางคืน = 밤」
2 A: โอเค แต่บอกหน่อยได้ไหม ไปไหน / 좋아. 그런데 어디 가는지 좀 말해 줄래? / 「บอกหน่อย = 좀 말해 주다」「ไปไหน = 어디 가다」
3 B: ไม่บอก จับให้แน่นนะ เดี๋ยวเร็ว / 안 말해. 꽉 잡아. 곧 빨라질 거야. / 「จับให้แน่น = 꽉 잡다」「เร็ว = 빠르다」
4 A: ได้ จับแล้ว ขับระวังหน่อยนะ / 알겠어. 잡았어. 조심해서 운전해. / 「จับแล้ว = 잡았어」「ระวัง = 조심하다」
5 B: สบายใจได้ ฉันขับเป็น ทางนี้สนุก / 안심해. 나 운전 잘해. 이 길이 재미있어. / 「สบายใจ = 안심하다」「ขับเป็น = 운전을 잘하다」
6 A: ลมเย็นดี กลางคืนแบบนี้เจ๋ง / 바람 시원하네. 이런 밤이 멋져. / 「ลมเย็น = 바람이 시원하다」「เจ๋ง = 멋지다」
7 B: จริงๆ ฉันพาไปที่ลับ ที่มีวิวสวยมาก / 사실 나 비밀 장소로 데려가는 거야. 경치 정말 예뻐. / 「ที่ลับ = 비밀 장소」「วิวสวย = 경치가 예쁘다」
8 A: ว้าว ขอบคุณที่พามา ดีใจมาก / 와. 데려와 줘서 고마워. 정말 기뻐. / 「พามา = 데려오다」「ดีใจมาก = 매우 기쁘다」
