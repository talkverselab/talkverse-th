1 A: พลอยครับ ประชุมเสร็จแล้วครับ ต่อไปนี้ห้ามพูดเรื่องงานนะครับ ไปกินข้าวเย็นด้วยกันไหมครับ / 플로이 씨, 회의 끝났어요. 이제부터 일 얘기 금지예요. 저녁 같이 먹을까요? / 「ห้าม = 금지하다」 「กินข้าวเย็น = 저녁을 먹다」
2 B: ได้เลยค่ะ ดิฉันก็เหนื่อยเหมือนกันค่ะ อยากกินอาหารไทยไหมคะ / 좋아요. 저도 피곤해요. 태국 음식 먹고 싶으세요? / 「ได้เลย = 좋아요」 「เหนื่อย = 피곤하다」
3 A: ดีครับ ผมชอบอาหารไทยมากเลยครับ โดยเฉพาะต้มยำ / 좋아요. 저 태국 음식 정말 좋아해요. 특히 똠얌요. / 「ชอบมาก = 아주 좋아하다」 「โดยเฉพาะ = 특히」
4 B: งั้นไปร้านที่ดิฉันรู้จักดีไหมคะ อาหารอร่อยมากเลยค่ะ / 그럼 제가 잘 아는 식당 갈까요? 음식이 정말 맛있어요. / 「รู้จัก = 알다」 「อร่อย = 맛있다」
5 A: เยี่ยมเลยครับ เดี๋ยวผมขับรถตามไปครับ หรือขึ้นแท็กซี่ไปด้วยกันไหมครับ / 아주 좋아요. 제가 차로 따라갈게요. 아니면 택시 같이 탈까요? / 「เยี่ยมเลย = 아주 좋아요」 「ขับรถ = 운전하다」
6 B: ขึ้นแท็กซี่ไปด้วยกันดีกว่าค่ะ สะดวกกว่าและไม่ต้องคุยงานด้วย / 택시 같이 타는 게 나을 거예요. 더 편하고 일 얘기도 안 해도 되니까요. / 「สะดวก = 편리하다」 「ดีกว่า = ~하는 편이 낫다」
7 A: โอเคครับ สัญญาไม่คุยงานนะครับ วันนี้พักผ่อนกันเถอะ / 알겠어요. 일 얘기 안 하기로 약속해요. 오늘은 쉬어요. / 「สัญญา = 약속하다」 「พักผ่อน = 휴식하다」
8 B: จริงๆ แล้วดิฉันเรียนภาษาเกาหลีมาหน่อยค่ะ เลยเข้าใจคำพูดของคุณตั้งแต่ตอนประชุมเลยค่ะ / 사실은 제가 한국어를 조금 배웠어요. 그래서 회의 때부터 당신의 말을 이해했어요. / 「จริงๆ แล้ว = 사실은」 「ตั้งแต่แรก = 처음부터」
