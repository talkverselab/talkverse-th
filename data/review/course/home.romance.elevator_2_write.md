2 B: ไม่มีอะไรหรอก แค่อยากเงียบๆ วันนี้ / 아무것도 아니야. 오늘은 그냥 조용히 있고 싶어. / 「อยากเงียบๆ = 조용히 있고 싶다」「วันนี้ = 오늘」
3 A: โอเค ผมฟังอยู่นะ ไม่ต้องพูดก็ได้ / 알겠어. 내가 듣고 있을게. 말 안 해도 돼. / 「ฟังอยู่ = 듣고 있다」「ไม่ต้องพูด = 말 안 해도 되다」
4 B: ขอบคุณนะ บางทีก็เหนื่อยกับการพูด / 고마워. 가끔은 말하는 게 피곤해. / 「เหนื่อย = 피곤하다」「การพูด = 말하는 것」
5 A: เข้าใจ อยู่ด้วยกันแบบนี้ก็ดีแล้ว / 이해해. 이렇게 같이 있는 것도 좋아. / 「เข้าใจ = 이해하다」「อยู่ด้วยกัน = 같이 있다」
6 B: ใช่ บางครั้งเงียบๆ ก็สบายใจ / 맞아. 가끔은 조용한 게 마음이 편해. / 「สบายใจ = 마음이 편하다」「บางครั้ง = 가끔」
7 A: จริงๆ ผมชอบเวลากับเบลแบบนี้ ใจมันอบอุ่น / 사실 나 벨이랑 이렇게 있는 시간 좋아해. 마음이 따뜻해. / 「ชอบเวลา = 시간을 좋아하다」「อบอุ่น = 따뜻하다」
8 B: ฉันก็เหมือนกัน ขอบคุณที่ฟัง / 나도 그래. 들어줘서 고마워. / 「เหมือนกัน = 똑같다」「ขอบคุณที่ฟัง = 들어줘서 고맙다」
