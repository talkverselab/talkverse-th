3 B: แมพมันผิดบ่อยในซอยนี้ ฉันอยู่ที่นี่มาหลายปี / 맵은 이 골목에서 자주 틀려. 나 여기 여러 해 살았어. / 「ผิดบ่อย = 자주 틀리다」「หลายปี = 여러 해」
4 A: แต่คราวที่แล้วเธอก็พาหลงเหมือนกัน / 그런데 저번에도 네가 길을 잃게 했잖아. / 「คราวที่แล้ว = 저번」「พาหลง = 길을 잃게 하다」

6 A: งั้นคราวนี้ลองตามเธอดู ถ้าผิดฉันชนะ / 그럼 이번엔 네 말 따라 볼게. 틀리면 내가 이긴 거야. / 「ตาม = 따르다」「ชนะ = 이기다」
7 B: ได้ เลี้ยวซ้ายตรงนี้ แล้วเดินตรงไปอีกนิด / 좋아. 여기서 왼쪽으로 돌아. 그리고 좀 더 직진해. / 「เลี้ยวซ้าย = 왼쪽으로 돌다」「อีกนิด = 좀 더」
8 A: เดี๋ยว แมพบอกขวา แต่เธอบอกซ้าย ตอนนี้สับสนหมดเลย ทางแยกนี้ไม่มีในแมพด้วย / 잠깐. 맵은 오른쪽인데 너는 왼쪽이래. 지금 완전 헷갈려. 이 교차로는 맵에도 없어. / 「สับสน = 헷갈리다」「ทางแยก = 교차로」
9 B: เห็นไหม แมพไม่มีซอยนี้ เชื่อฉันเถอะ ใกล้แล้ว / 봤지? 맵에 이 골목 없어. 날 믿어. 거의 다 왔어. / 「ไม่มี = 없다」「ใกล้แล้ว = 거의 다 오다」
10 A: โอเค ยอมแพ้ คราวนี้เธอชนะ ไปตามเธอ / 알겠어. 항복할게. 이번엔 네가 이겨. 네 말 따라갈게. / 「ยอมแพ้ = 항복하다」「ไปตาม = 따라서 가다」
11 B: ดีแล้ว การยอมแพ้บางทีก็คือการชนะนะ / 잘했어. 항복하는 게 때로는 이기는 거야. / 「ยอมแพ้ = 항복」「การชนะ = 이기는 것」
