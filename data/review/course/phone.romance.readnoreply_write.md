1 A: เห็นข้อความแล้วทำไมไม่ตอบครับ สามชั่วโมงแล้ว / 메시지 봤는데 왜 답 안 해요? 세 시간 됐어요. / เห็นข้อความแล้ว = 메시지를 봤다 · ไม่ตอบ = 답하지 않다
2 B: ยุ่งนิดหน่อย ตอบช้าไปหน่อย ขอโทษนะ / 좀 바빴어. 답이 늦었네. 미안. / ยุ่งนิดหน่อย = 좀 바쁘다 · ตอบช้า = 답이 늦다
3 A: ไม่เป็นไรครับ แต่ผมรออยู่ / 괜찮아요. 그런데 저 기다리고 있었어요. / ไม่เป็นไร = 괜찮다 · รออยู่ = 기다리고 있다
4 B: หึงเหรอ ที่ฉันไม่ตอบเร็ว / 질투해? 내가 빨리 답 안 해서. / หึง = 질투하다 · ไม่ตอบเร็ว = 빨리 답하지 않다
5 A: ไม่หึงครับ แค่สงสัยเฉยๆ / 질투 안 해. 그냥 궁금했을 뿐이야. / ไม่หึง = 질투하지 않다 · สงสัยเฉยๆ = 그냥 궁금하다
6 B: ตอบว่าไม่หึงแบบนี้คือแพ้แล้วนะ / 이렇게 "질투 안 해"라고 하면 진 거야. / ตอบว่า = ~라고 답하다 · แพ้แล้ว = 이미 졌다
7 A: จริงๆผมหึงนิดหน่อย ถึงได้ทักมา / 사실 좀 질투했어. 그래서 연락한 거야. / จริงๆ = 사실은 · หึงนิดหน่อย = 좀 질투하다
8 B: รู้แล้ว ฉันก็รอข้อความคุณเหมือนกัน / 알았어. 나도 네 메시지 기다리고 있었어. / รู้แล้ว = 알았다 · รอข้อความ = 메시지를 기다리다
