1 A: สวัสดีครับ ผมมาขอเงินประกันคืนครับ ครบตามสัญญาแล้ว / 안녕하세요. 보증금 돌려받으러 왔어요. 계약대로 다 됐어요. / 「เงินประกัน = 보증금」「ตามสัญญา = 계약대로」
2 B: ได้ค่ะ แต่มีรอยบนผนัง ต้องหักค่าซ่อมบางส่วนนะคะ / 알겠어요. 그런데 벽에 자국이 있어서 수리비 일부 공제해야 해요. / 「รอยบนผนัง = 벽의 자국」「หักค่าซ่อม = 수리비 공제」
3 A: รอยนั้นไม่ใช่ผมทำครับ ตอนย้ายเข้ามาก็มีอยู่แล้ว / 그 자국은 제가 낸 게 아니에요. 이사 들어올 때부터 있었어요. / 「ไม่ใช่ผมทำ = 제가 한 게 아니다」「ย้ายเข้ามา = 이사 들어오다」
4 B: มีหลักฐานไหมคะ ปกติเราหักถ้ามีรอยใหม่ / 증거 있나요? 보통 새 자국 있으면 공제해요. / 「หลักฐาน = 증거」「รอยใหม่ = 새 자국」
5 A: มีครับ ผมถ่ายรูปตอนเข้าอยู่ แล้วส่งในไลน์ไว้ / 있어요. 들어올 때 사진 찍어서 라인에 보냈어요. / 「ถ่ายรูป = 사진 찍다」「ส่งในไลน์ = 라인에 보내다」
6 B: ขอดูไลน์หน่อยได้ไหมคะ จะเช็คให้เลย / 라인 좀 봐도 될까요? 바로 확인해 드릴게요. / 「ขอดู = 좀 보다」「เช็คให้ = 확인해 주다」
7 A: ได้ครับ นี่ข้อความและรูปตอนวันแรกเลย / 네. 여기 첫날 메시지랑 사진이에요. / 「ข้อความ = 메시지」「วันแรก = 첫날」
8 B: เห็นแล้วค่ะ จริงๆ รอยนี้มีตั้งแต่ก่อนคุณเข้า ฉันลืมเช็ค / 봤어요. 사실 이 자국은 당신이 들어오기 전부터 있었어요. 제가 확인을 깜빡했어요. / 「มีตั้งแต่ก่อน = 전부터 있다」「ลืมเช็ค = 확인을 깜빡하다」
9 A: งั้นคืนเต็มจำนวนได้ไหมครับ ตามที่ตกลงไว้ / 그럼 전액 돌려주실 수 있나요? 약속대로요. / 「เต็มจำนวน = 전액」「ตกลงไว้ = 약속해 둔」
10 B: ได้ค่ะ ขอโทษที่เข้าใจผิด จะโอนให้วันนี้เลย / 알겠어요. 오해해서 죄송해요. 오늘 바로 송금해 드릴게요. / 「เข้าใจผิด = 오해하다」「โอนให้ = 송금하다」
11 A: ขอบคุณครับ ไม่เป็นไร ดีที่หลักฐานชัดเจน / 감사합니다. 괜찮아요. 증거가 명확해서 다행이에요. / 「ไม่เป็นไร = 괜찮다」「ชัดเจน = 명확하다」
12 B: ครั้งหน้าจะระวังให้ดีกว่านี้ค่ะ ขอบคุณที่เข้าใจ / 다음엔 더 조심할게요. 이해해 줘서 고마워요. / 「ครั้งหน้า = 다음」「ระวัง = 조심하다」
