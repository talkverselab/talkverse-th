1 B: ไปไหนครับ วันนี้จะไปตลาดใช่ไหม / 어디 가세요? 오늘 시장 가시는 거죠? / 「ไปไหน = 어디 가다」「ตลาด = 시장」
2 A: ใช่ครับ ไปตลาดใกล้ๆ ครับ / 네. 가까운 시장 가요. / 「ใกล้ๆ = 가까운」「ไปตลาด = 시장에 가다」
3 B: คนอื่นสามสิบบาท แต่คุณยี่สิบบาทครับ / 다른 사람은 삼십 바트인데 당신은 이십 바트예요. / 「คนอื่น = 다른 사람」「สามสิบ = 삼십」
4 A: ทำไมถูกกว่าคนอื่นครับ / 왜 다른 사람보다 싸요? / 「ถูกกว่า = 더 싸다」「ทำไม = 왜」
5 B: เพราะพูดไทยได้ เลยคิดราคาคนในซอย / 태국어 하니까 골목 사람 가격으로 해요. / 「พูดไทยได้ = 태국어를 할 수 있다」「คนในซอย = 골목 사람」
6 A: จริงเหรอครับ ผมอยู่ที่นี่มาครึ่งปีแล้ว / 정말요? 저 여기서 반년 살았어요. / 「ครึ่งปี = 반년」「อยู่มา = 살아왔다」
7 B: รู้แล้วครับ เลยถือว่าเป็นคนในครอบครัวซอย / 알고 있어요. 그래서 골목 식구로 봐요. / 「ถือว่า = ~로 여기다」「ครอบครัวซอย = 골목 식구」
8 A: ขอบคุณมากครับ ผมดีใจที่ได้เป็นส่วนหนึ่ง / 정말 감사해요. 일부가 되어 기뻐요. / 「ส่วนหนึ่ง = 일부」「ดีใจ = 기쁘다」
