1 A: กินข้าวหรือยังครับ / 밥 먹었어요? / กินข้าวหรือยัง = 밥 먹었나요 · หรือยัง = 이미 ~했나요
2 B: ยังเลย วันนี้ยุ่งมาก ยังไม่ได้กิน / 아직이야. 오늘 너무 바빠서 아직 못 먹었어. / ยังเลย = 아직이야 · ยุ่งมาก = 너무 바쁘다
3 A: งั้นไปกินด้วยกันไหม ผมเลี้ยง / 그럼 같이 먹을래? 내가 살게. / ไปกินด้วยกัน = 같이 먹으러 가다 · ผมเลี้ยง = 내가 살다
4 B: ได้สิ แต่อย่าเพิ่งบอกว่ารักนะ / 좋아. 그런데 아직 사랑한다고 하지는 마. / อย่าเพิ่ง = 아직은 ~하지 마 · บอกว่ารัก = 사랑한다고 말하다
5 A: ผมแค่ถามว่ากินหรือยังเอง / 난 그냥 밥 먹었냐고 물은 거야. / แค่ถาม = 그냥 묻다 · เอง = 그냥/뿐
6 B: รู้ๆ แต่คำนี้ในไทยมันมีความหมายมากกว่านั้น / 알아. 그런데 태국어에서 이 말은 그 이상의 의미가 있어. / มีความหมายมากกว่า = 더 많은 의미가 있다 · รู้ๆ = 알아
7 A: จริงๆผมชอบคุณนะ ถึงได้ถามบ่อย / 사실 나 당신이 좋아서 자주 묻는 거야. / จริงๆ = 사실은 · ถามบ่อย = 자주 묻다
8 B: ฉันก็เหมือนกัน ถึงได้ตอบทุกครั้ง / 나도 그래. 그래서 매번 대답하는 거야. / เหมือนกัน = 마찬가지다 · ตอบทุกครั้ง = 매번 대답하다
