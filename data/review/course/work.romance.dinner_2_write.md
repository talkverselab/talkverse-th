1 B: เย็นนี้เรามีกฎนะคะ ห้ามพูดเรื่องงานค่ะ ถ้าพูดต้องดื่มเบียร์ลงโทษนะคะ / 오늘 저녁 우리 규칙 있어요. 일 얘기 금지예요. 말하면 벌주로 맥주 마셔야 해요. / กฎ = 규칙, ลงโทษ = 벌
2 A: เข้าใจครับ แล้วเราจะคุยเรื่องอะไรดีครับ ผมอยากคุยเรื่องทำงานที่กรุงเทพครับ / 알겠어요. 그럼 무슨 얘기 할까요? 저 방콕에서 일하는 얘기 하고 싶어요. / เข้าใจ = 이해하다, คุยเรื่อง = 얘기하다
3 B: อ๋อ พูดเรื่องงานแล้วนะคะ ต้องดื่มเบียร์ลงโทษเลยค่ะ / 어, 일 얘기 했네요. 벌주로 맥주 바로 마셔야 해요. / อ๋อ = 어, เลย = 바로
4 A: ขอโทษครับ ผมพูดผิดครับ ผมหมายถึงเรื่องเดินทางครับ ไม่ใช่ทำงานครับ / 죄송해요. 제가 말을 잘못했어요. 여행 얘기를 말한 거예요, 일 얘기가 아니에요. / พูดผิด = 말을 잘못하다, หมายถึง = 의미하다
5 B: เข้าใจค่ะ งั้นคุยเรื่องอาหารไทยดีกว่าไหมคะ / 이해했어요. 그럼 태국 음식 얘기하는 게 더 나을까요? / งั้น = 그럼, ดีกว่า = 더 낫다
6 A: ดีครับ ผมชอบอาหารไทยมากครับ โดยเฉพาะต้มยำกุ้งครับ / 좋아요. 저 태국 음식 정말 좋아해요. 특히 새우 똠얌이요. / โดยเฉพาะ = 특히, ต้มยำกุ้ง = 새우 똠얌
7 B: ต้มยำกุ้งรสเผ็ดไหมคะ เดี๋ยวสั่งให้ค่ะ / 새우 똠얌 매운가요? 곧 주문해 드릴게요. / รสเผ็ด = 매운 맛, เดี๋ยว = 곧
8 A: ขอบคุณมากครับ ตอนนี้เราคุยเรื่องอาหารอย่างเดียวครับ ไม่พูดเรื่องงานแล้วครับ / 정말 감사합니다. 이제 우리 음식 얘기만 해요. 일 얘기는 안 할게요. / ตอนนี้ = 지금, อย่างเดียว = 만
