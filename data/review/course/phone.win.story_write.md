1 A: เธอพูดว่าอยู่บ้านนะ แต่สตอรี่เมื่อกี้เห็นเธออยู่ที่คาเฟ่กับผู้ชายคนหนึ่ง ใครวะ / 너는 집에 있다고 했잖아. 그런데 방금 스토리에 카페에서 남자랑 같이 있는 거 봤는데, 누구야? / สตอรี่ = 스토리; ใครวะ = 누구야 (캐주얼)
2 B: กำลังพูดอะไรของเธอเนี่ย ฉันอยู่บ้านจริงๆ น่าจะสตอรี่เก่า / 뭐라는 거야. 나 진짜 집에 있었어. 아마 옛날 스토리일 거야. / กำลังพูดอะไร = 뭐라는 거야; สตอรี่เก่า = 옛날 스토리
3 A: ไม่ใช่ครับ เพิ่งโพสต์เมื่อกี้เอง อย่าโกหกผมสิ / 아니야. 방금 전에 올렸잖아. 거짓말하지 마. / เพิ่งโพสต์ = 방금 올리다; อย่าโกหก = 거짓말하지 마
4 B: เธอคิดมากไปแล้ว เพื่อนธรรมดาเอง ไม่เห็นต้องซีเรียส / 네가 너무 생각하는 거야. 그냥 친구야. 그렇게 진지할 필요 없어. / คิดมากไป = 너무 생각하다; ซีเรียส = 진지하다
5 A: เพื่อนหรอ นั่งใกล้กันขนาดนั้น อธิบายให้ชัดๆ หน่อยครับ / 친구라고? 그렇게 가까이 앉아서. 제대로 설명해 봐. / นั่งใกล้กัน = 가까이 앉다; อธิบายให้ชัดๆ = 명확히 설명하다
6 B: ทำไมต้องสงสัยขนาดนี้ ฉันไม่ต้องรายงานทุกอย่างให้เธอหรอก / 왜 이렇게 의심하는 거야. 내가 모든 걸 보고할 필요는 없잖아. / สงสัยขนาดนี้ = 이렇게 의심하다; รายงานทุกอย่าง = 모든 것을 보고하다
7 A: เพราะเธอพูดว่าอยู่บ้าน แล้วไปโผล่ที่นั่น บอกความจริงมาเถอะครับ / 왜냐하면 집에 있다고 하고 거기 나타났잖아. 사실을 말해. / ไปโผล่ = 나타나다; บอกความจริง = 사실을 말하다
8 B: ก็ได้ตามใจ มันไม่ใช่แบบที่เธอคิดหรอก อย่ามานั่งดราม่า / 마음대로 해. 네가 생각하는 그런 거 아니야. 드라마 만들지 마. / ตามใจ = 마음대로; นั่งดราม่า = 드라마를 만들다
9 A: งั้นบอกมาสิว่าใคร ผมมีสิทธิ์รู้ครับ / 그럼 누구인지 말해. 내가 알 권리가 있어. / มีสิทธิ์รู้ = 알 권리가 있다
10 B: โอเค เป็นน้องชายฉันเอง เพิ่งมาจากเชียงใหม่กะทันหัน เลยไปกินกาแฟกัน ฉันไม่อยากบอกเพราะเธอชอบหึงแม้แต่ครอบครัว / 알겠어. 내 남동생이야. 갑자기 치앙마이에서 와서 커피 마시러 갔어. 네가 가족한테까지 질투해서 말하고 싶지 않았어. / น้องชาย = 남동생; กะทันหัน = 갑자기; หึง = 질투하다
11 A: อ๋อ น้องชายเหรอ ทำไมไม่บอกตั้งแต่แรก ผมขอโทษที่เข้าใจผิด / 아, 남동생이야? 처음부터 왜 안 말했어. 오해해서 미안해. / ตั้งแต่แรก = 처음부터; เข้าใจผิด = 오해하다
12 B: ก็กลัวเธอจะโมโหไง คราวหน้าอย่าด่วนตัดสินใจนะ / 네가 화낼까 봐 그랬어. 다음엔 성급하게 판단하지 마. / กลัวเธอจะโมโห = 네가 화낼까 봐; ด่วนตัดสินใจ = 성급하게 판단하다
