2 B: ไม่เป็นไร เธอกินสิ ยังเหลือ / 괜찮아. 네가 먹어. 아직 남았잖아. / ไม่เป็นไร = 괜찮아 · เธอกินสิ = 네가 먹어 / ไม่เป็นไร, ยังเหลือ

3 A: ไม่เอา ต้นกินสิ เต็มแล้ว / 안 돼. ต้น이 먹어. 나 배 가득이야. / เต็มแล้ว = 가득 찼어(오용) · กินสิ = 먹어 / ไม่เอา, เต็มแล้ว

4 B: 555 อิ่มแล้วนะ ไม่ใช่เต็ม / 555 배부른 거지, 가득 찬 게 아냐. / อิ่มแล้ว = 배불렀어 · ไม่ใช่ = ~가 아냐 / อิ่มแล้ว, ไม่ใช่

5 A: เอ๊ะ เด็กหยิบไปแล้วว่ะ! / 어? 애가 집어 갔어! / หยิบไปแล้ว = 집어 갔어 · ว่ะ = 헐(구어) / เด็ก, หยิบไปแล้ว

6 B: แม่เค้าสั่งเพิ่มทั้งถาดเลย / 엄마가 한 판 더 시켰어. / สั่งเพิ่ม = 더 시키다 · ทั้งถาด = 한 판 통째 / สั่งเพิ่ม, ทั้งถาด

7 A: จริงดิ เว่อร์มาก 555 / 진짜야? 너무 오버다 555 / จริงดิ = 진짜야? · เว่อร์มาก = 너무 오버 / จริงดิ, เว่อร์มาก
