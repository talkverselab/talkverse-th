1 A: ฟ้า อยากได้อะไร
/ ฟ้า 뭐 마실래?
/ อยากได้ = 원하다 · อะไร = 뭐
/ อยากได้, อะไร

2 B: ชาเย็น ไม่หวาน นะ
/ 아이스티, 안 달게.
/ ชาเย็น = 아이스티 · ไม่หวาน = 안 달게
/ ชาเย็น, ไม่หวาน

3 A: โอเค หวานมาก ครับ
/ 오케이, 아주 달게.
/ หวานมาก = 아주 달게 · ครับ = 존댓말 반사
/ หวานมาก, ครับ

4 B: ไม่หวาน! 555
/ 안 달게라고! ㅋㅋㅋ
/ ไม่ = 안 · 555 = ㅋㅋㅋ
/ ไม่, 555

5 C: หวานมาก ใช่ไหม
/ 아주 달게 맞죠?
/ หวานมาก = 아주 달게 · ใช่ไหม = 맞죠?
/ ใช่ไหม, หวานมาก

6 A: ใช่ ครับ หวานมาก
/ 네, 아주 달게요.
/ ใช่ = 네 · ครับ = 습관
/ ใช่, ครับ

7 B: หวานเว่อร์ มาก 555
/ 달콤 폭발이네 ㅋㅋㅋ
/ เว่อร์ = 과장되다 · หวานเว่อร์ = 달콤 폭발
/ เว่อร์, หวานเว่อร์

8 B: ...หวาน... เหมือนเธอ
/ …달다… 너처럼
/ หวาน = 달다 · เหมือน = ~처럼
/ เหมือน, เธอ
