1 A: ฟ้า อยากดื่มอะไรดีครับ / 파, 뭐 마시고 싶어? / อยากดื่มอะไร = 뭐 마시고 싶어 · ครับ = 말끝 (반사적으로 붙임) / อยาก, ดื่ม, อะไร
2 B: ไอซ์ลาเต้ ไม่หวานนะ / 아이스 라떼, 안 달게. / ไม่หวาน = 안 달게 · นะ = 부드럽게 끝맺음 / ไอซ์ลาเต้, ไม่, หวาน
3 A: ได้ครับ ไอซ์ลาเต้ หวานมาก / 오케이, 아이스 라떼 엄청 달게. / หวานมาก = 엄청 달게 (실수) · ได้ครับ = 알겠어 / หวานมาก, ได้
4 C: หวานมากขนาดไหนอ่ะ / 얼마나 달게 해드릴까요? / หวานมาก = 엄청 달게 · ขนาดไหน = 얼마나 / ขนาด, อ่ะ
5 A: ใช่ครับ ใส่น้ำเชื่อมเยอะๆ / 응, 시럽 왕창 넣어 주세요. / ใส่น้ำเชื่อม = 시럽 넣다 · เยอะๆ = 많이 / น้ำเชื่อม, เยอะ
6 B: เฮ้ย {name} ไม่หวานสิ หยุดนะ / 야 {name}, 안 달게라고, 멈춰! / ไม่หวาน = 안 달게 · สิ = 강조해서 말함 / ไม่หวาน, หยุด
7 C: น้ำเชื่อมหมด หวานเว่อร์เลย / 시럽 다 썼어, 완전 달아. / หมด = 다 떨어지다 · เว่อร์ = 과장되게 / หมด, เว่อร์
8 B: หวานจัง... เหมือนเธออะ / 달아... 너처럼. / หวานจัง = 달다 · เหมือนเธอ = 너처럼 / หวาน, เหมือน, เธอ
