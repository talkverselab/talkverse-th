1 A: ผมมาแจ้งความเรื่องพาสปอร์ตหายครับ / 여권 분실 신고하러 왔습니다. / แจ้งความ = 신고하다 · พาสปอร์ตหาย = 여권 분실 / แจ้งความ, พาสปอร์ต, หาย / polite|worried
2 B: ได้ครับ หายตอนไหน ที่ไหน / 네. 언제, 어디서 잃어버리셨나요? / หายตอนไหน = 언제 잃어버렸나 · ที่ไหน = 어디서 / หาย, ตอนไหน, ที่ไหน / calm|polite
3 A: เมื่อวานที่สถานีรถไฟครับ / 어제 기차역에서요. / เมื่อวาน = 어제 · สถานีรถไฟ = 기차역 / เมื่อวาน, สถานี, รถไฟ / worried
4 B: กรอกใบแจ้งความได้เลยครับ / 신고서 작성하세요. / ใบแจ้งความ = 신고서 · กรอก = 작성하다 / ใบแจ้งความ, กรอก, ได้เลย / polite
5 A: ขอบคุณครับ ผมไม่แน่ใจเวลาแน่นอน / 감사합니다. 정확한 시간은 확실하지 않아요. / ไม่แน่ใจ = 확실하지 않다 · เวลา = 시간 / ขอบคุณ, ไม่แน่ใจ, เวลา / flustered
6 B: ไม่เป็นไร เขียนเท่าที่จำได้ / 괜찮아요. 기억하는 만큼 쓰세요. / เท่าที่จำได้ = 기억하는 만큼 · ไม่เป็นไร = 괜찮다 / ไม่เป็นไร, เขียน, จำได้ / calm
7 A: หายตอนขึ้นรถไฟครับ ประมาณบ่าย / 기차 탈 때 잃어버렸어요. 오후쯤이요. / หายตอน = ~할 때 잃어버리다 · ประมาณ = 대략 / หาย, ตอน, ประมาณ / worried
8 B: ตรวจสอบกระเป๋าอีกครั้งไหม / 가방을 다시 확인해 보실래요? / ตรวจสอบ = 확인하다 · กระเป๋า = 가방 / ตรวจสอบ, กระเป๋า, อีกครั้ง / polite
9 A: เจอแล้วครับ ในกระเป๋าด้านใน / 찾았어요. 가방 안쪽 주머니에 있었어요. / เจอแล้ว = 찾았다 (chaos) · ด้านใน = 안쪽 / เจอ, แล้ว, ด้านใน / surprised|relieved
10 B: ดีมากครับ ใบแจ้งความไม่ต้องใช้แล้ว / 아주 좋아요. 신고서는 이제 필요 없어요. / ใบแจ้งความ = 신고서 · ไม่ต้องใช้ = 필요 없다 / ดีมาก, ใบแจ้งความ, ไม่ต้อง / cheerful|polite
11 A: ขอโทษที่รบกวนครับ โล่งใจมาก / 귀찮게 해서 죄송합니다. 정말 안도돼요. / โล่งใจ = 안도하다 · ขอโทษ = 죄송합니다 / ขอโทษ, รบกวน, โล่งใจ / grateful|relieved
12 B: ไม่เป็นไร โชคดีที่เจอเร็ว / 괜찮아요. 빨리 찾아서 다행이에요. / โชคดี = 다행이다 · เจอเร็ว = 빨리 찾다 / ไม่เป็นไร, โชคดี, เจอ / gentle|cheerful
13 A: ขอบคุณครับ ครั้งหน้าจะระวังมากขึ้น / 감사합니다. 다음엔 더 조심하겠습니다. / ระวัง = 조심하다 · ครั้งหน้า = 다음 / ขอบคุณ, ครั้งหน้า, ระวัง / grateful|polite
