1 A: ขอโทษครับ ห้องน้ำอยู่ที่ไหนครับ / 죄송한데 화장실 어디예요? / ห้องน้ำ = 화장실 · อยู่ที่ไหน = 어디에 있어요 / ขอโทษ, ห้องน้ำ, ที่ไหน
2 B: อยู่ชั้นสองค่ะ ขึ้นลิฟต์ตรงนั้นไปนะ / 2층에 있어요 저쪽 엘리베이터 타고 올라가 / ชั้นสอง = 2층 · ขึ้นลิฟต์ = 엘리베이터 타다 / ชั้นสอง, ลิฟต์, ขึ้น
3 A: ชั้นสองครับ ขอบคุณมากครับ ใช่ทางนี้ไหม / 2층이요 정말 고마워요 이쪽 길 맞아요? / ขอบคุณ = 고마워요 · ใช่ไหม = 맞나요 / ขอบคุณ, มาก, ทางนี้
4 B: ไม่ใช่ค่ะ เลี้ยวซ้ายก่อนถึงจะขึ้น / 아니에요 왼쪽으로 먼저 꺾어야 올라가요 / เลี้ยวซ้าย = 왼쪽으로 꺾다 · ไม่ใช่ = 아니에요 / เลี้ยว, ซ้าย, ก่อน
5 C: เอ๊ะ ผิดแล้วครับ ห้องน้ำอยู่ชั้นล่าง / 어? 틀렸어요 화장실은 지하층이에요 / ผิดแล้ว = 틀렸어요 · ชั้นล่าง = 지하층 / ผิด, ชั้นล่าง
6 A: งั้นชั้นไหนครับ ผมสับสนหมดแล้ว / 그럼 몇 층이에요 저 완전 헷갈려요 / สับสน = 헷갈리다 · งั้น = 그럼 / สับสน, งั้น, หมด
7 D: ไม่ใช่ทั้งคู่ค่ะ ไปชั้นสามทางบันได / 둘 다 아니에요 3층 계단 쪽으로 가요 / ชั้นสาม = 3층 · บันได = 계단 / ชั้นสาม, บันได, ทั้งคู่
8 B: งั้นเดี๋ยวฉันพาไปเองค่ะ... / 그럼 제가 직접 데려다 드릴게요... / พาไปเอง = 직접 데려다 주다 · เดี๋ยว = 잠시 / พาไป, เอง, เดี๋ยว
