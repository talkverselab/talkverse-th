치앙마이 산길 회화 장면 컷 4장입니다. (점토·펠트 인형 톤, 둥근 얼굴, 따뜻한 조명, 파스텔 배경 / 글자·말풍선 없음 / 3:2 가로, 인물 크게)

캐릭터는 첨부 시트 기준으로 고정했습니다.

A (학습자 남): 짧은 갈색 머리, 파란 티셔츠, 네이비 반바지, 흰 운동화, 갈색 크로스백
B (ต้น): 짧은 검정 머리, 베이지 셔츠, 갈색 바지, 흰 운동화
C (แม่ค้า): 곱슬 머리, 꽃무늬 셔츠 + 갈색 앞치마

cut1 — “산 같이 가볼까? 멀어?” / “가자, 느긋하게. 그렇게 멀진 않아”

산 전망 길에서 A가 산을 가리키며 제안하고, B가 여유롭게 동의하는 장면.

cut2 — “오토바이 빌렸어. 길 잃었는데 길 좀 물어볼게” / “저 교차로에서 우회전해”

산길에서 길을 잃은 A가 당황하고, B가 오른쪽을 가리키며 알려 주는 장면. (스쿠터 배경)

cut3 — “좌회전이라고 그럼?” / “우회전이지, 좌 아냐 555 또 길 잃었어 완전”

A가 헷갈려 머리를 긁적이는 동안 B가 웃으며 다시 오른쪽을 가리키는 장면.

cut4 — “저 가게에서 물어볼게. 산은 어느 쪽이야” / “오른쪽으로 가요~ 좀 멀어요~” / “이 가게 세 번째야…” / “너랑 길 잃는 것도 나쁘진 않네”

시골 과일 노점에서 아주머니(C)가 오른쪽을 가리키고, A와 B가 웃으며 듣는 장면.

모든 컷에 글자·말풍선·간판 텍스트는 넣지 않았습니다. 표정과 몸짓으로 대사의 감정(설렘 → 당황 → 헷갈림/웃음 → 따뜻한 여운)이 드러나도록 구성했습니다. 앱에서 말풍선을 얹어 쓰시면 됩니다. 수정이나 추가 컷이 필요하면 말씀해 주세요!
