「하트 세 개」 장면 컷 4장

캐릭터 시트 스타일(점토·펠트 인형, 둥근 얼굴, 따뜻한 조명, 파스텔)을 유지했습니다.

각 컷은 세로 분할 구도(왼쪽·오른쪽 각자 다른 방·침대), 폰 화면 글자 없음, 말풍선·자막·간판 글자 없음.

A = 학습자(남, 시트 3번 스타일), B = ต้น(시트 2번), C = ฟ้า(시트 1번).

cut1 (A: 잘못 보냄 → B: 555 폭탄)

왼쪽 A 놀람·당황 / 오른쪽 B 크게 웃음

cut2 (A: 너무 부끄러워 → B: 555 진짜 ครับ까지?)

왼쪽 A 더 부끄러워 손 가림 / 오른쪽 B 계속 웃음

cut3 (A: ฟ้า만! 그룹에 잘못 → B: 그럼 나도 받았지 555 chill)

왼쪽 A 설명·당황 제스처 / 오른쪽 B 여유롭게 웃음

cut4 (A: 부끄러워 죽겠네 → C: ❤️ …받았어)

왼쪽 A 얼굴 가리며 부끄러움 / 오른쪽 C(ฟ้า) 부드러운 미소로 폰 확인

요청하신 규칙(글자 없음, 3:2 가로, 인물 크게, 각자 다른 장소, 같은 인물·옷)을 지켰습니다. 필요하면 표정·구도·배경만 미세 조정해 드릴게요.
