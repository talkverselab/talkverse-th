1 A: ฟ้า วันนี้แก้วเหมือนกันเลยนะครับ บังเอิญจัง
/ ฟ้า, 오늘 컵이 똑같네. 완전 우연이야.
/ แก้วเหมือนกัน = 컵이 똑같다 · บังเอิญ = 우연
/ แก้ว, เหมือนกัน, บังเอิญ

2 B: โอ้โห จริงเหรอคะ ใครเห็นหรือเปล่าเนี่ย
/ 어머, 진짜요? 누가 봤어?
/ จริงเหรอคะ = 정말인가요 · ใครเห็น = 누가 봤나
/ โอ้โห, จริงเหรอ, เห็น

3 A: ไม่มีอะไรครับ เดี๋ยวผมเอาไปซ่อนในตู้
/ 아무것도 아니야. 내가 캐비닛에 숨겨올게.
/ ไม่มีอะไร = 아무것도 아니다 · ซ่อนในตู้ = 캐비닛에 숨기다
/ ไม่มีอะไร, ซ่อน, ตู้

4 B: ซ่อนอะไร 555 ใครจะไม่รู้ เดี๋ยวไปสลับกับคนอื่นดีกว่า
/ 뭘 숨겨 555 누가 모르겠어. 다른 사람 거랑 바꿔.
/ ใครจะไม่รู้ = 누가 모르겠어 · สลับ = 바꾸다
/ ซ่อน, สลับ, 555

5 C: เฮ้ย แก้วฉันหายไปไหน ใครเอาไปเนี่ย
/ 야, 내 컵 어디 갔어. 누가 가져갔어?
/ ใครเอาไป = 누가 가져갔나 · หายไป = 없어졌다
/ หายไป, ใคร, เอาไป

6 A: เอ่อ บังเอิญหรือเปล่าครับ
/ 어, 우연인가.
/ บังเอิญหรือเปล่า = 우연인가 · เอ่อ = 어
/ เอ่อ, บังเอิญ, หรือเปล่า

7 B: บังเอิญอะไร แก้วหายไปชัดๆ เอาอันนี้ไปซ่อนก่อน เดี๋ยวคนอื่นมา
/ 무슨 우연이야 컵 없어진 게 뻔해. 이거 먼저 숨겨 사람들 오기 전에.
/ บังเอิญอะไร = 무슨 우연이야 · ชัดๆ = 뻔해
/ ชัดๆ, ซ่อน, เดี๋ยว

8 C: ทุกคนมาดูหน่อย แก้วใครหายไปบ้าง วุ่นวายเลย
/ 다들 좀 와 봐. 누구 컵 없어졌어. 완전 난리네.
/ แก้วใคร = 누구 컵 · วุ่นวาย = 난리
/ ทุกคน, วุ่นวาย, บ้าง

9 A: ผมไม่มีอะไรเกี่ยวข้องครับ จริงๆ
/ 나 관련 없어. 진짜로.
/ ไม่มีอะไรเกี่ยวข้อง = 관련 없다 · จริงๆ = 진짜로
/ เกี่ยวข้อง, ไม่มีอะไร, จริงๆ

10 B: บอกทุกคนไปเลยไหม...
/ 그냥 다들한테 말해버릴까...
/ บอกไปเลย = 그냥 말해버리자 · ทุกคน = 다들
/ บอก, ทุกคน, ไปเลย
