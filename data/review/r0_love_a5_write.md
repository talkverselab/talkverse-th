1 B: สวัสดีค่ะ เห็นคุณทุกวันเลยนะคะ / 안녕하세요, 매일 보이시네요 / เห็นทุกวัน = 매일 보다 · นะคะ = 부드러운 말끝 / สวัสดี, ทุกวัน, เห็น
2 A: สวัสดีครับ ผม {name} ครับ เห็นคุณบ่อยเหมือนกันครับ / 안녕하세요, 저 {name}이에요 저도 자주 봐요 / เหมือนกัน = 나도 같아 · บ่อย = 자주 / บ่อย, เหมือนกัน, ชื่อ
3 B: อ้าว จริงเหรอคะ คุณลงที่ไหนคะ / 어? 진짜요? 어디 내리세요? / อ้าว = 어 그런가 · ลงที่ไหน = 어디 내리다 / อ้าว, ลง, ที่ไหน
4 A: ผมลงที่สยามครับ แต่ตอนนี้เลยไปแล้วครับ / 저는 시암에서 내리는데 지금 이미 지나친 것 같아요 / เลยไป = 지나가 버리다 · แต่ = 그런데 / สยาม, เลยไป, ตอนนี้
5 B: 555 อ้าว คุณเลยสถานีไปแล้วเหรอคะ / 555 어, 역 지나쳐 버렸네요? / 555 = 웃음 · เลยสถานี = 역을 지나치다 / 555, สถานี, เหรอ
6 A: ใช่ครับ ตกใจเลยครับ ลงไม่ทันครับ / 네, 깜짝 놀랐어요 내릴 타이밍 놓쳤어요 / ตกใจ = 깜짝 놀라다 · ไม่ทัน = 제때 못 하다 / ตกใจ, ทัน, ลง
7 B: ...ฉันตั้งใจเลยไปเหมือนกันนะ / ...나도 일부러 지나쳤어 / ตั้งใจ = 일부러 · นะ = 말끝 흐림 / ตั้งใจ, ฉัน, เหมือนกัน
8 A: จริงเหรอครับ ผมก็เหมือนกันครับ / 진짜요... 저도 똑같아요 / จริงเหรอ = 진짜요 · ก็ = 도 / จริง, ก็, เหมือนกัน
