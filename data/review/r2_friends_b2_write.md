4 A: มังกร! ผมเป็นมังกรนะ / 용! 저는 용이에요. / มังกร = 용 (띠를 별자리로 착각) · เป็นมังกร = 용띠다 / มังกร, เป็น, นะ
5 B: มังกรเหรอ 555 ดูดวงให้เลยมั้ย? โชคดีมากนะ / 용이라고? ㅋㅋ 운세 바로 봐줄까? 운 엄청 좋다며. / ดูดวง = 운세 보다 · 555 = ㅋㅋ / ดูดวง, เหรอ, โชคดี
6 C: เอาจริง ราศีอะไรจริงๆ อ่ะ? / 진짜로, 별자리 뭐야 진짜? / เอาจริง = 진짜로 · จริงๆ = 정말로 / เอาจริง, จริงๆ, อ่ะ
7 C: ราศีเราเข้ากันดีนะ... / 우리 별자리 잘 맞는데... / เข้ากันดี = 잘 맞다 · ราศีเรา = 우리 별자리 / เข้ากันดี, ราศี, นะ

9 B: ชิลๆ สิ เดี๋ยวดูให้หมด / 편하게 해. 다 봐줄게. / ชิลๆ = 편하게 · เดี๋ยวดูให้ = 봐줄게 / ชิลๆ, เดี๋ยว, หมด
