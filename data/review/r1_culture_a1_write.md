3 A: อ๋อ ขอโทษครับ ลืมไปเลย / 아, 미안해 깜빡했어. / ขอโทษครับ = 미안해(남성 존대 반사) · ลืมไปเลย = 완전히 깜빡하다 / ขอโทษ, ลืม, ครับ
4 A: เดี๋ยวถอดให้เองครับ / 내가 직접 벗을게. / ถอดให้ = (남 거) 벗겨 주다 — 실수, ถอดเอง 의도 · เอง = 직접 / เอง, ให้
5 B: 555 ถอดให้ใครไง รองเท้าตัวเองสิ / 555 누구 거 벗겨 주는 거야, 네 신발이잖아. / 555 = ㅋㅋㅋ · ตัวเอง = 자기 거 · สิ = 당연히/강조 / 555, ตัวเอง, สิ
