1 A: ฟ้า วิ่ง! ฝนตกแล้ว ไปกันเร็ว!
/ 파 뛰어! 비 온다 빨리 가자!
/ วิ่ง = 뛰어 · ฝนตก = 비가 오다 · ไปกัน = 가자
/ วิ่ง, ฝนตก, ไปกัน

2 B: ไปกัน! จับมือแน่นๆ นะ ลื่นนะ
/ 가자! 손 꽉 잡아 미끄러워
/ จับมือ = 손을 잡다 · ลื่น = 미끄럽다
/ จับมือ, แน่น, ลื่น

3 A: ได้ครับ! วิ่งครับ ฟ้า
/ 네! 뛰어요 파
/ ได้ = 알겠어 · ครับ = 존댓말 끝(친구에게 쓰면 어색)
/ ได้, ครับ, วิ่ง

4 B: 555 ครับอะไรอ่ะ ชิลๆ วิ่งเร็วกว่านี้!
/ 555 ครับ이 뭐야 편하게 더 빨리 뛰어!
/ 555 = ㅋㅋㅋ · ชิลๆ = 편하게 · เร็ว = 빨리
/ 555, ชิลๆ, เร็ว

5 A: โอ้ย! ลื่นจัง! ขอโทษนะ มะม่วงกลิ้งไปหมด
/ 으악! 완전 미끄러워! 미안해 망고 다 굴러간다
/ ขอโทษ = 미안해 · กลิ้ง = 굴러가다 · มะม่วง = 망고
/ ขอโทษ, มะม่วง, กลิ้ง

6 C: เฮ้ย! มะม่วงของป้า! อย่าวิ่ง เก็บก่อนสิ!
/ 어이! 내 망고야! 뛰지 말고 먼저 주워!
/ ของป้า = 아주머니 거 · เก็บ = 주우다 · สิ = 좀
/ มะม่วง, ป้า, เก็บ

7 A: ขอโทษครับ ป้า! เดี๋ยวเก็บให้ครับ
/ 죄송해요 아주머니! 지금 주워드릴게요
/ เดี๋ยว = 곧 · เก็บให้ = 주워 주다 · ครับ = 존댓말 끝(반사)
/ ขอโทษ, เดี๋ยว, เก็บให้

8 B: มือ... ยังไม่ปล่อยนะ {name} 555 เปียกหมดแล้ว
/ 손... 아직 안 놨네 {name} 555 완전 젖었어
/ มือ = 손 · ยังไม่ปล่อย = 아직 안 놓다 · เปียก = 젖다
/ มือ, ปล่อย, เปียก
